# 发票工作台

个人使用的本地发票整理网页。服务只监听 `127.0.0.1`，工作数据保存在你选择的 Mac 本地目录。

## 使用方法

1. 第一次使用，双击 `首次安装.command`，选择工作目录并等待浏览器打开。
2. 以后使用，双击 `启动发票工作台.command`；重复双击会复用当前服务。
3. 使用结束，双击 `关闭发票工作台.command`。

如果 macOS 首次阻止脚本运行，请在 Finder 中右键脚本并选择“打开”。安装需要本机已有 Node.js 22+ 和 pnpm。

## 开发验证

```bash
pnpm verify
pnpm test:e2e
node scripts/start.mjs --dry-run
```

`--dry-run` 只显示本地地址和工作目录，不启动服务，也不会输出启动口令。
